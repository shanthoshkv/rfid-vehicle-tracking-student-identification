## [0.1.0] - 2026-11-19
### Added
- ESP32 + MFRC522 firmware sketches: serial-only, LCD, OLED, mobile-hotspot and UID-reader variants.
- PHP/MySQL backend (`rfid_system/`): `verify.php` entry/exit logging, admin panel for users and logs, live security dashboard.
- `Website/` landing page, write-ups in `docs/` and literature papers in `Resources/`.
- Sanity-check CI workflow, MIT license, contributing guide and issue templates.
