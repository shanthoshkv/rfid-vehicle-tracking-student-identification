Problems We're Solving

Why we built this system - real issues that needed fixing

⏱️

Slow Manual Verification

Anyone who's been through the gate during rush hour knows - manual checks take forever. We're talking 10 seconds per vehicle during peak times. Our automated system gets it done in under 3 seconds with RFID scan and instant database lookup.

🔒

Security Gaps

Manual checking is prone to human errors, fake IDs slip through, and there's no consistent record keeping. With RFID verification against our database plus photo display, we get foolproof authentication every time with complete audit trails.

📋

Poor Record Management

Paper logbooks are impossible to search through and analyze. Our MySQL database with web interface lets security instantly pull up anyone's record, see entry patterns, and generate reports. Plus everything's backed up digitally.

🚗

Single Vehicle Limitation

Students with multiple vehicles had to carry different cards or get multiple registrations. Now one RFID handles all their vehicles - system shows complete list when scanned so security knows exactly what they own.

📸

No Visual Verification

Guards had to rely on ID photos which could be old or unclear. Our system displays the registered photo instantly when card is scanned - makes visual verification super quick and prevents card swapping.

📊

Zero Data Insights

With paper logs, analyzing traffic patterns or peak hours was basically impossible. Our dashboard provides real-time statistics, shows trends, and helps administration make data-driven decisions about campus security.

Tech Stack We Used

From RFID hardware to full-stack web development - here's everything

📡

RFID Hardware

MFRC522 (RC522) modules reading passive 13.56MHz RFID tags. These connect via SPI to our microcontrollers which handle the communication with our PHP backend through WiFi.

MFRC522 13.56MHz Tags SPI Protocol Long Range
🔌

Microcontrollers

ESP32 boards with built-in WiFi. They send HTTP POST requests directly to our PHP server without needing a computer middleman. Programming done in Arduino IDE with C++.

ESP8266 ESP32 WiFi Built-in Arduino IDE
🐘

Backend Language

PHP 8.x powering the entire backend - handles user authentication, database operations, form processing, and API endpoints for ESP32 communication. Running on Apache through XAMPP.

PHP 8.x Apache Server XAMPP Stack Session Management
🗄️

Database

MySQL 8.0 storing everything - users table with email, phone, Aadhar, access logs for entries, exits, proper foreign keys linking records, and indexes on frequently queried columns for speed.

MySQL 8.0 Relational Schema Foreign Keys Indexed Queries
🌐

Frontend

Modern HTML5, CSS3 with custom dark theme, and vanilla JavaScript for real-time updates. JetBrains Mono font throughout for that clean developer aesthetic. Fully responsive design works on any screen size.

HTML5 CSS3 JavaScript ES6 Responsive

Security & Validation

Admin login system, prepared SQL statements preventing injection attacks, input validation on all forms, Aadhar number format checking, file type validation for photo uploads.

Authentication SQL Injection Prevention Input Validation File Security

System Architecture

How everything connects - four layers working together seamlessly

🔧

Hardware Layer

ESP8266/ESP32 microcontrollers with MFRC522 RFID readers mounted at gates. Tags embedded in student ID cards. LED/buzzer feedback for successful/failed scans. Powered via USB or 5V supply with WiFi connecting to campus network.

🌐

Communication Layer

ESP32 sends HTTP POST requests with UID and vehicle number to PHP endpoint. Server queries MySQL, checks authorization, and returns JSON response. Security gate polls server every 2 seconds for latest data.

💻

Application Layer

PHP backend handling all logic - user CRUD operations, log management with bulk delete, authorization checks, photo storage with USN naming, session management for admin authentication, API endpoints for ESP32 and Ajax.

🖥️

Presentation Layer

Three web interfaces - Admin dashboard for management, Security gate for live monitoring with photos and vehicle lists, Database admin through phpMyAdmin. All using consistent dark theme with responsive design.
